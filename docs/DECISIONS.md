# Decisions (change only when I say so)
- Android Auto Backup is OFF (android:allowBackup=false) for now.
- Manual backup is part of the free plan.
- A custom rule profile is supported: the parent types required hours and/or days.
- Real Google Play Billing is NOT built until I ask. A fake entitlement service is used first.
- Pace uses calendar days across the school year.
- State profiles are placeholders until I research the official sources myself.
- Backup encryption: Not built in Step 9. Suggestion for a future release: optional password-based backup encryption (e.g. AES-256) could be offered to parents who store backup zip files in shared or cloud storage.
